# Vault de aprendizados (esqueleto)

Copie esta pasta para dentro do seu vault Obsidian (ou use como pasta comum de Markdown) e aponte `<VAULT>` para ela.

```
patterns/   soluções reutilizáveis e guias de framework (com verified-against-version)
pitfalls/   armadilhas: sintoma, causa raiz, como evitar, como detectar
projects/   um diretório por projeto: _index.md + um post-mortem por feature
```

Quem escreve: `scribe` ao fim de cada feature; `research`, devs e reviewers quando encontram uma lacuna (protocolo de gap de memória).
